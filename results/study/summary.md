# evalnoise study results

Profile `quick`. Generated by `evalnoise study`; do not edit by hand.

Standard deviations (square roots of the variance components) in each dataset's
unit, with 95% intervals: percentile bootstrap over clusters for item-level
components, a Burdick-Graybill (MLS) interval for the run component, capped at
(range / 2)^2 for bounded scores. `n/i`: not identified by
the layout; `(in X)`: folded into component X. `<0`: the moment estimate is
negative (planning uses 0); `upper bound < 0`: so is the upper end of its bootstrap
interval, a hint that the model may overstate the noise of cell means there (with few
informative items the draws resample the same items). `[degenerate]`: no run variance
fits the MLS interval (the runs agree more closely than the residual allows, or
runs and residual are both exactly 0, which carries no information).

One run per arm, the observed tasks and repeats. SE: of the difference in arm means.
MDE: smallest difference detected with 80% power at alpha 0.05 (two-sided t,
Satterthwaite df). Where identified, the run variance is borrowed from this
dataset with its degrees of freedom, so the MDE is large when the dataset has few
replicate runs. Where it is not identified the MDE assumes it is zero, which
understates the MDE if runs vary. Pass/fail datasets: the larger of the smallest
detectable gain and loss, with the shifted arm's variance at its own pass rate where
that is larger.
Naive false-positive rate: how often a paired test over items, which ignores run
effects, declares a difference between single runs of two arms with equal mean
scores (their item x arm effects still differ; identical arms give a higher rate).
(few): some pair of arms differs on fewer than 10 items. With two
arms these numbers rest on those few items; with more, the pooled components also
use the other arms, but that pair's numbers stay unreliable (see the planning notes).

## Planning notes

- `mm-arena-replicated`: within-run noise is not separated from item x run noise: repeats inside a run are assumed not to help (conservative)
- `mm-arena-replicated`: the replicated arms do not share one item x run variance (Brown-Forsythe p = 2.7e-07; SD by arm: claude-cli:claude-fable-5-1@high 7.6, claude-cli:claude-haiku-5-5@high 18.3, claude-cli:claude-opus-5-5@high 10.8, claude-cli:claude-sonnet-5-5@high 13.2): pooled components describe an average arm
- `mm-arena-replicated`: items are clustered (median design effect 1.24 over pairs): the tasks-needed counts multiply the item-level variance by it; the grid and reference-design MDEs treat items as independent
- `mm-arena-replicated`: items are also clustered by family (median design effect 2.42 over pairs, from only 5 families, so rough): counting items as independent, or only clusters as dependent, overstates the information
- `mm-arena-all`: within-run noise is not separated from item x run noise: repeats inside a run are assumed not to help (conservative)
- `mm-arena-all`: the replicated arms do not share one item x run variance (Brown-Forsythe p = 2.7e-07; SD by arm: claude-cli:claude-fable-5-1@high 7.6, claude-cli:claude-haiku-5-5@high 18.3, claude-cli:claude-opus-5-5@high 10.8, claude-cli:claude-sonnet-5-5@high 13.2): pooled components describe an average arm
- `mm-arena-all`: items are clustered (median design effect 1.18 over pairs): the tasks-needed counts multiply the item-level variance by it; the grid and reference-design MDEs treat items as independent
- `mm-arena-all`: items are also clustered by family (median design effect 2.74 over pairs, from only 5 families, so rough): counting items as independent, or only clusters as dependent, overstates the information
- `agent-ab-no-tests`: run variance set to 0 (not identified by the data)
- `agent-ab-no-tests`: item x run noise is folded into item_arm: extra runs are assumed not to reduce it (conservative)
- `agent-ab-no-tests`: pass/fail scores at a 94.0% pass rate: the shifted arm's variance is taken at its own rate where that is larger, and the MDE is the larger of gain and loss
- `agent-ab-no-tests`: arms differ on fewer than 10 items (control - no-tests: 9): those pairs' SEs, MDEs and intervals rest on those few items and are unreliable
- `agent-ab-no-tests-cost`: run variance set to 0 (not identified by the data)

The bootstrap interval and the item-level SEs ignore run-to-run variation. SE,
clusters: cluster-robust, tested with clusters - 1 df (equals the items-only SE when
each item is its own cluster). SE, families: clustered by item family where the
dataset defines one (few families, so rough). Where the run variance is identified,
the SE with run term adds run / R for each arm (R: its number of runs; the
run-adjusted item means average every run equally, so a partial replicate run counts
as a whole run), tested with Satterthwaite df using the run term's own df. p, run
variance without one arm: the range of that p-value when the run variance (and its
df) is re-estimated without each replicated arm in turn, since the pooled value
averages arms that differ.
